# Answer key

137 stances on nine propositions (`../registry/propositions.json`), one JSON object per line, one
file per topic (`T1` documentation, `T2` students' demands, `T3` the sound on 15 March, `T4` crowd
sizes). Each record names the actor (from `../registry/actors.json`), the stance or value, the date
it was first published in the corpus, one to three evidence URLs, and a one-sentence English
paraphrase. `stance_change_of` links a stance to the same actor's earlier, different stance.

Built from the in-scope articles of canopy-collapse-news-2024-2025 v1.1.0 by searching each topic
with the same patterns across all nine outlets. The records were extracted by a model (Claude) from
that search, each with its evidence URLs; paraphrases are the model's
English, not quotes. Only stances attributed to an actor in the article
are recorded, never an outlet's own voice or a columnist's opinion, and no private persons. The key
is not exhaustive: some stances in the corpus are missing, and some are dated later than their
first appearance.
